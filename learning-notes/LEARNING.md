# MiniMind專案學習指南

## 專案功能梳理

MiniMind是一個極小型語言模型專案，其核心理念是"大道至簡"—用最小的模型實現基本的大型語言模型功能。這個專案旨在讓任何人都能用極低的成本（甚至只需3元人民幣和2小時）從零開始訓練一個能夠對話的語言模型。

### 專案主要特點：

1. **極小模型體積**：最小版本僅為25.8M，是GPT-3的1/7000大小
2. **低訓練成本**：單卡3090顯卡即可訓練
3. **完整訓練流程**：包含從數據處理到模型部署的全流程代碼
4. **原生實現**：核心算法全部使用PyTorch從零實現，不依賴第三方庫的抽象接口
5. **多種模型變種**：提供Dense模型和MoE（混合專家）模型兩種架構

### 核心功能模塊：

1. **數據處理**：
   - Tokenizer訓練與應用
   - 預訓練、SFT、DPO等各階段數據集處理

2. **模型架構**：
   - Transformer結構的Decoder-Only架構
   - MoE（混合專家）模型架構

3. **訓練流程**：
   - 預訓練(Pretrain)：模型學習基礎知識
   - 監督微調(SFT)：模型學習對話方式
   - LoRA微調：參數高效微調方法
   - 人類反饋強化學習(RLHF/DPO)：優化模型回應偏好
   - 知識蒸餾(KD)：小模型學習大模型知識

4. **模型應用**：
   - 命令行問答接口
   - WebUI界面
   - 兼容OpenAI API的服務端

## 函式交互邏輯

整個專案的函式交互邏輯可以簡化為以下流程：

1. **數據流**：
   - 原始文本 → 分詞器(Tokenizer) → 數值Token序列 → 訓練數據批次
   - 用戶輸入 → 分詞器 → 模型預測 → 分詞器解碼 → 自然語言輸出

2. **模型訓練流**：
   - 初始化模型 → 載入數據 → 前向傳播(計算loss) → 反向傳播(更新參數) → 保存模型

3. **推理流程**：
   - 載入模型 → 接收輸入 → 分詞處理 → 模型預測下一個token → 循環生成 → 輸出結果

4. **各階段訓練的關係**：
   - 預訓練(Pretrain) → 監督微調(SFT) → [可選：LoRA微調/DPO強化學習/模型蒸餾]

## 研究路線圖及時間期程表

以下是針對你背景和學習目標設計的研究路線圖，總計約12週：

### 第1-2週：基礎理解與環境準備
- 閱讀項目README，理解整體架構
- 準備Python環境和必要庫
- 熟悉PyTorch基礎操作
- 理解Transformer和語言模型基本原理
- 搭建訓練環境，下載預處理好的數據

### 第3-4週：模型架構與數據處理
- 學習MiniMind的模型結構(./model/)
- 理解分詞器(Tokenizer)的工作原理
- 研究數據處理流程，包括清洗和格式化
- 嘗試運行評估腳本，熟悉模型效果

### 第5-6週：預訓練與監督微調
- 深入研究預訓練(train_pretrain.py)代碼
- 理解監督微調(train_full_sft.py)實現
- 嘗試小規模訓練(可使用較小的數據集)
- 分析訓練loss曲線，理解模型學習過程

### 第7-8週：LoRA微調技術
- 學習LoRA原理與實現(model_lora.py)
- 研究LoRA微調過程(train_lora.py)
- 嘗試自定義數據集進行LoRA微調
- 對比全參數微調與LoRA微調的效果差異

### 第9-10週：DPO強化學習演算法
- 研究DPO原理與實現(train_dpo.py)
- 理解人類反饋數據的格式與處理
- 理解DPO訓練流程與實現細節
- 嘗試運行小規模DPO訓練實驗

### 第11-12週：模型蒸餾與綜合應用
- 學習知識蒸餾原理(train_distillation.py)
- 研究白盒/黑盒蒸餾的區別與實現
- 嘗試將不同階段的技術整合應用
- 開發簡單應用，如問答系統或WebUI

## 學習建議

1. **循序漸進**：按照上述路徑從基礎到進階逐步學習，不要急於理解所有內容

2. **實踐為主**：閱讀代碼的同時嘗試運行，修改參數觀察效果

3. **概念先行**：在深入代碼前，先了解相關機器學習概念(如Transformer、微調、強化學習)

4. **資源準備**：如果想嘗試訓練，至少準備一張現代GPU(如RTX 3060以上)

5. **耐心學習**：大語言模型相關技術較為複雜，需要耐心和持續學習

6. **擴展閱讀**：參考README中引用的論文和相關項目，拓展知識面

祝你學習順利！如有任何問題，歡迎隨時提問。
