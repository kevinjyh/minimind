# PyTorch 和 NumPy 中的維度操作：dim 和 axis 的理解

## 基本概念

### 維度表示方式

- PyTorch 使用 `dim` 參數
- NumPy 使用 `axis` 參數
- 兩者的概念相同，只是命名不同

### 常見誤解

初學者常見的誤解是將 "沿著某維度計算" 與該維度的結果混淆。例如：

- 誤解："沿著行（axis=0）計算" 應該得到每一行的結果
- 實際：沿著行的方向計算實際上會得到每一列的結果

## 維度操作的正確理解

### 1. 基本原則

- `dim=0` 或 `axis=0`：表示在行的方向上進行操作，影響列的計算，**Zero is for rows**
- `dim=1` 或 `axis=1`：表示在列的方向上進行操作，影響行的計算，**One is for columns**

### 2. 實際示例

```python
x = np.array([[1, 2, 3],
              [4, 5, 6]])
```

#### 使用 axis=0（沿著行方向）

```python
np.sum(x, axis=0)  # 結果: array([5, 7, 9])
```

- 計算過程：
  - 第一列：1 + 4 = 5
  - 第二列：2 + 5 = 7
  - 第三列：3 + 6 = 9

#### 使用 axis=1（沿著列方向）

```python
np.sum(x, axis=1)  # 結果: array([6, 15])
```

- 計算過程：
  - 第一行：1 + 2 + 3 = 6
  - 第二行：4 + 5 + 6 = 15

## 有效的記憶方法

### 1. 方向記憶法

- `dim=0` 或 `axis=0`：想像成「從上到下」的操作
- `dim=1` 或 `axis=1`：想像成「從左到右」的操作

### 2. 結果導向記憶法

- `axis=0`：結果將保留列的數量（消除行）
- `axis=1`：結果將保留行的數量（消除列）

### 3. 視覺化記憶

```text
axis=0 的方向：  ↓ ↓ ↓
                [1 2 3]
                [4 5 6]

axis=1 的方向：  → → →
                [1 2 3]
                [4 5 6]
```

## 實際應用注意事項

### 1. 保持維度

- 使用 `keepdims=True`（NumPy）或 `keepdim=True`（PyTorch）可以保持原始維度
- 這在某些需要維持張量形狀的操作中很有用

### 2. 多維張量

- 原則相同，但需要注意更多的維度方向
- 可以同時指定多個維度進行操作

## 常見操作示例

### 1. 求和操作

```python
# PyTorch
torch.sum(x, dim=0)  # 沿著行方向求和
torch.sum(x, dim=1)  # 沿著列方向求和

# NumPy
np.sum(x, axis=0)  # 沿著行方向求和
np.sum(x, axis=1)  # 沿著列方向求和
```

### 2. 平均值操作

```python
# PyTorch
torch.mean(x, dim=0)  # 沿著行方向求平均
torch.mean(x, dim=1)  # 沿著列方向求平均

# NumPy
np.mean(x, axis=0)  # 沿著行方向求平均
np.mean(x, axis=1)  # 沿著列方向求平均
```
