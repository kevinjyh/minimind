# MiniMind Full SFT 測試案例說明

本目錄包含針對 `train_full_sft.py` 的完整測試案例，旨在幫助理解代碼的運作原理和功能。

## 測試案例功能說明

### 1. test_model_initialization.py

- 測試模型初始化過程
- 驗證模型參數載入
- 檢查模型架構配置
- 觀察模型參數分佈

### 2. test_data_loading.py

- 測試數據載入流程
- 驗證數據預處理
- 檢查批次大小和序列長度
- 觀察數據格式轉換

### 3. test_learning_rate.py

- 測試學習率調整機制
- 驗證學習率計算公式
- 觀察學習率變化趨勢
- 分析不同學習率策略

### 4. test_training_loop.py

- 測試訓練循環流程
- 驗證損失計算
- 檢查梯度更新
- 觀察訓練過程中的參數變化

### 5. test_full_sft_parameters.py

- 測試 Full SFT 特定參數
- 驗證模型配置
- 檢查訓練參數
- 分析參數影響

## 參數調整指南

### 模型初始化參數

- `dim`: 模型維度，影響模型容量
- `n_layers`: 層數，影響模型深度
- `max_seq_len`: 最大序列長度
- `use_moe`: 是否使用混合專家模型

### 訓練參數

- `batch_size`: 批次大小，影響訓練穩定性
- `learning_rate`: 學習率，影響收斂速度
- `epochs`: 訓練輪數
- `grad_clip`: 梯度裁剪閾值

### 數據參數

- `data_path`: 訓練數據路徑
- `max_length`: 序列最大長度
- `num_workers`: 數據載入工作進程數

## 學習順序建議

1. **基礎概念理解**
   - 先閱讀 `test_model_initialization.py`
   - 了解模型架構和參數配置
   - 觀察模型初始化過程

2. **數據處理流程**
   - 研究 `test_data_loading.py`
   - 理解數據預處理步驟
   - 掌握批次處理機制

3. **訓練機制**
   - 學習 `test_learning_rate.py`
   - 理解學習率調整策略
   - 觀察學習率變化

4. **完整訓練流程**
   - 分析 `test_training_loop.py`
   - 掌握訓練循環細節
   - 理解損失計算和梯度更新

5. **進階特性**
   - 研究 `test_full_sft_parameters.py`
   - 探索特定參數影響
   - 優化訓練效果

## 測試案例使用建議

1. **循序漸進**
   - 按照建議順序逐步學習
   - 每個測試案例都包含詳細註釋
   - 可以修改參數觀察變化

2. **視覺化分析**
   - 查看 `visualizations` 目錄下的圖表
   - 分析參數變化趨勢
   - 理解模型行為

3. **參數實驗**
   - 調整關鍵參數
   - 觀察模型表現
   - 記錄實驗結果

4. **深入理解**
   - 研究代碼實現細節
   - 分析性能瓶頸
   - 優化訓練效果
