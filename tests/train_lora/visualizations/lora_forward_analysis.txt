LoRA 前向傳播特性分析

初始 LoRA 輸出範數: 0.000000

不同 alpha 縮放因子的效果:
alpha=0: 輸出範數=0.000000
alpha=0.25: 輸出範數=0.143634
alpha=0.5: 輸出範數=0.287268
alpha=1.0: 輸出範數=0.574536
alpha=2.0: 輸出範數=1.149072

LoRA 前向傳播公式:
Y = X + alpha * (B * A * X) / r
其中:
  X = 輸入特徵
  A = 低秩投影矩陣 (到 r 維空間)
  B = 低秩投影矩陣 (從 r 維空間)
  r = LoRA 秩(rank)
  alpha = 縮放因子
