LoRA 應用策略:
1. LoRA 僅應用於方陣類型的線性層 (輸入維度 = 輸出維度)
2. 這種選擇性應用可以減少參數量，同時保持關鍵層的可塑性
3. 每個應用了 LoRA 的層，在前向傳播時會計算: output = original(x) + lora(x)
