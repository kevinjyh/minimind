LoRA 記憶體效率分析

不同模型大小下的記憶體使用比較:
模型維度 dim=64:
  完整模型記憶體: 1.92 MB
  LoRA 參數記憶體: 0.02 MB
  記憶體節省: 99.19%

模型維度 dim=128:
  完整模型記憶體: 4.56 MB
  LoRA 參數記憶體: 0.03 MB
  記憶體節省: 99.32%

模型維度 dim=256:
  完整模型記憶體: 11.63 MB
  LoRA 參數記憶體: 0.06 MB
  記憶體節省: 99.46%

模型維度 dim=512:
  完整模型記憶體: 34.01 MB
  LoRA 參數記憶體: 0.12 MB
  記憶體節省: 99.63%

LoRA 記憶體優勢:
1. 顯著降低參數量，減少存儲需求
2. 微調時只需更新少量參數，降低 GPU 記憶體壓力
3. 多個 LoRA 權重可以共享同一個基礎模型
4. 適合在資源受限的設備上進行模型部署和微調
