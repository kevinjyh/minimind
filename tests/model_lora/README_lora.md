# LoRA（Low-Rank Adaptation）測試指南

本文檔旨在幫助您通過測試案例理解 LoRA 的工作原理和實現細節。LoRA 是一種參數高效的模型微調技術，通過添加低秩矩陣來調整預訓練模型的權重，而無需更新所有原始參數。

## [LoRA的工作原理](../../learning-notes/topics/LoRA的工作原理.md)

## 測試案例概述

測試被分為兩個主要文件：

- `test_lora.py`：測試基本結構和功能
- `test_lora_training.py`：測試 LoRA 在訓練場景中的應用

### test_lora.py 中的測試案例

#### TestLoRA 類

1. **test_lora_initialization**：
   - 測試 LoRA 層的初始化是否正確
   - 驗證矩陣 A 和 B 的尺寸是否符合預期
   - 檢查初始化方式（A 使用正態分佈，B 為零）

2. **test_lora_forward**：
   - 測試 LoRA 的前向傳播
   - 確認輸出形狀是否正確
   - 驗證計算路徑是否正確遵循 A->B 的順序

3. **test_different_ranks**：
   - 測試不同秩值對 LoRA 的影響
   - 驗證不同秩值下矩陣尺寸的變化

#### TestApplyLoRA 類

1. **test_apply_lora**：
   - 測試 apply_lora 函數是否正確應用到模型上
   - 檢查是否只有方形矩陣的線性層被應用了 LoRA
   - 驗證前向傳播函數是否被正確修改

2. **test_lora_forward_with_model**：
   - 測試將 LoRA 應用到模型後的前向傳播
   - 由於 B 矩陣初始化為零，確認初始輸出應與原始模型相同

3. test_apply_lora_to_small_model 測試
   - 對小型 MiniMindLM 模型應用 LoRA，秩為 8
   - 首先識別並計數模型中所有符合條件的方陣線性層
   - 檢查 LoRA 應用後的情況：
      - 確認所有方陣線性層都應用了 LoRA
      - 驗證 LoRA 的秩設置正確
      - 確保前向傳播方法已被修改
   - 最後執行模型的前向傳播，確保模型仍然能正常工作

4. test_apply_lora_to_moe_model 測試
   - 對帶有 MoE (Mixture of Experts) 的 MiniMindLM 模型應用 LoRA，秩為 16
   - 與第一個測試類似，但專門針對 MoE 結構的模型
   - 驗證在複雜的 MoE 架構中，LoRA 仍能正確應用於所有符合條件的線性層
   - 確認應用 LoRA 後，MoE 模型的前向傳播功能仍然正常

這兩個測試將幫助您確認 apply_lora 函數能夠正確地疊加低秩層於不同配置的 MiniMindLM 模型中的 nn.Linear 層，並且不會破壞模型的基本功能。
這些測試案例會：

   1. 識別和統計模型中所有符合條件的方陣線性層
   2. 確認這些層在應用 LoRA 後被正確修改
   3. 驗證模型在應用 LoRA 後仍能正常運行

#### TestSaveLoadLoRA 類

1. **test_save_load_lora**：
   - 測試 LoRA 權重的保存和加載功能
   - 驗證權重是否能夠正確保存和恢復

2. **test_partial_lora_loading**：
   - 測試在有多個 LoRA 層的情況下，權重的保存和加載
   - 驗證不同層之間的權重是否能夠正確對應

### test_lora_training.py 中的測試案例

#### TestLoRATraining 類

1. **test_lora_parameter_count**：
   - 比較 LoRA 參數量與原始模型參數量
   - 驗證 LoRA 是否確實降低了需要訓練的參數數量

2. **test_lora_training**：
   - 測試僅訓練 LoRA 參數而凍結原始網絡
   - 確認原始參數在訓練後保持不變
   - 驗證 LoRA 參數是否有適當更新

3. **test_fine_tuning_effect**：
   - 比較 LoRA 微調與全參數微調的效果
   - 評估參數效率和性能之間的權衡
   - 分析 LoRA 在領域適應任務中的效果

## 如何調整測試參數深入理解 LoRA

### 1. 探索秩值的影響

秩值是 LoRA 的核心參數，決定了低秩矩陣的大小：

```python
# 在 test_different_ranks 中嘗試不同的秩值
ranks = [1, 2, 4, 8, 16, 32, 64]
```

較低的秩值意味著更少的參數，但可能限制表達能力；較高的秩值則相反。通過調整秩值並觀察性能變化，可以理解 LoRA 中秩值選擇的重要性。

### 2. 調整初始化參數

嘗試不同的初始化方法和參數：

```python
# 在 LoRA 類的 __init__ 方法中修改
self.A.weight.data.normal_(mean=0.0, std=0.1)  # 嘗試不同標準差
self.B.weight.data.normal_(mean=0.0, std=0.01)  # 嘗試非零初始化 B
```

這將幫助您理解初始化對 LoRA 收斂速度和穩定性的影響。

### 3. 嘗試不同的層選擇策略

默認情況下，`apply_lora` 僅應用於方形矩陣的線性層，但您可以嘗試修改選擇策略：

```python
# 修改 apply_lora 函數中的條件
if isinstance(module, nn.Linear):  # 應用於所有線性層
```

這可以幫助理解為什麼 LoRA 通常只應用於特定層，以及不同選擇策略的效果。

### 4. 探索不同的學習率和優化器

在 `test_lora_training` 中嘗試不同的優化設置：

```python
# 嘗試不同的優化器
optimizer = torch.optim.Adam([p for name, p in model.named_parameters() if p.requires_grad], lr=0.01)
```

```python
# 為 LoRA 參數使用較高的學習率
lora_params = [p for name, p in model.named_parameters() if 'lora' in name]
optimizer = torch.optim.SGD([{'params': lora_params, 'lr': 0.1}], lr=0.01)
```

## `training_dynamics.png`，LoRA 訓練動態 - 領域適應

這張圖展示了LoRA的另一個關鍵優勢：**任務適應能力**。

- **資料點**：
  - 藍色點：原始數據（正弦函數+隨機噪聲）
  - 橙色方塊：新數據（餘弦函數+隨機噪聲）

- **曲線**：
  - 黑色實線：預訓練模型（擬合正弦函數）
  - 其他顏色線：不同訓練輪次後的LoRA模型預測

- **訓練過程**：
  1. 0輪：模型行為與預訓練模型一致（擬合正弦）
  2. 10輪：開始偏離原始任務
  3. 25-50輪：過渡階段，部分適應新任務
  4. 100-200輪：成功適應到新任務（擬合餘弦）

- **關鍵意義**：
  - 展示了LoRA如何通過更新極少量參數，使模型從一個任務（正弦擬合）平滑過渡到另一個任務（餘弦擬合）
  - 體現了模型適應新領域時的漸進學習過程
  - 證明了不需要重新訓練整個模型，只需調整低秩矩陣即可實現有效的領域轉換

這兩張圖完美展示了LoRA技術的核心價值：以極少的計算和存儲成本，實現大型模型的有效適應和調整。

## 熱力圖視角下的 LoRA 權重變化解析

這兩張圖展示了 LoRA 如何對神經網絡權重進行微調，讓我以更直觀的方式解釋這些熱力圖的含義。

### `rank_effect.png`，不同秩值對權重的影響

這張圖包含6個子圖，從左到右分別是：原始權重、秩=1、秩=2、秩=4、秩=8、秩=16的效果。

#### 直觀理解

想像這些熱力圖是代表「調整旋鈕」的面板：

- **原始權重**：代表模型的初始設定，呈現隨機的紅藍模式（正負值）
- **不同秩值的效果**：展示了用不同數量的「調整旋鈕」對模型進行微調的結果

隨著秩值增加（從1到16）：

- **調整精度增加**：秩=1時只能進行粗略調整，秩=16時可以進行更精細的調整
- **保留原始特徵**：即使進行調整，仍能看到與原始權重相似的紅藍模式，表明模型的基本功能得到保留
- **細微變化增多**：秩越高，熱力圖中可見的細微變化越多，表明更多的局部特徵得到調整

### `weight_transformation.png`，LoRA 貢獻機制解析

這張圖包含3個子圖：原始權重、LoRA 貢獻 (BA)、組合權重 (W + BA)。
在這張圖中，抬頭「LoRA 貢獻 (BA)」中的 `BA` 代表的是 **"B"** 和 **"A"** 兩個矩陣的乘積，具體來說：

- **A**：這是 LoRA 模型中的一個低秩矩陣，通常用來捕捉輸入特徵的某些重要信息。
- **B**：這是另一個低秩矩陣，通常用來將 A 的輸出轉換為最終的權重調整。

#### LoRA 的工作原理

在 LoRA 中，權重的調整是通過以下公式來實現的：

$$
\text{Adjusted Weight} = W + BA
$$

其中：

- \( W \) 是原始權重矩陣。
- \( BA \) 是由矩陣 \( B \) 和 \( A \) 的乘積所產生的貢獻。

#### 意義

- **LoRA 貢獻 (BA)**：這個熱力圖展示了在應用 LoRA 機制後，矩陣 \( B \) 和 \( A \) 的乘積對原始權重的影響。它顯示了這些低秩矩陣如何在不改變整體結構的情況下，對權重進行微調。
- **可視化效果**：通過這個圖，您可以直觀地看到 LoRA 如何在不同的秩值下，對權重進行調整，並且這些調整的大小和方向。

總結來說，`BA` 是 LoRA 機制中關鍵的數學運算，幫助模型在保持原始結構的同時，進行有效的參數調整。

#### 直觀理解

想像這是一種「照片修飾」過程：

- **原始權重**：相當於原始照片
- **LoRA 貢獻**：相當於修飾層，注意它的顏色深度較淺（數值範圍小，約為原始權重的 1/20）
- **組合權重**：相當於最終修飾後的照片

關鍵觀察：

1. **微調而非重構**：LoRA 貢獻的值非常小（注意中間圖的色彩範圍僅為 ±0.01），這意味著它只對原始權重進行輕微調整，而不是完全重寫

2. **高效修改**：即使是如此小的修改，也能在最終權重中產生有意義的變化，這正是 LoRA 的核心優勢 — 用少量參數實現有效調整

3. **保留整體結構**：比較原始權重和組合權重，可以發現整體結構得到保留，只有部分區域有變化，這意味著模型的基本能力不會丟失

### 總結

這些熱力圖展示了 LoRA 的工作方式：它通過較小的低秩矩陣來對原始權重進行微調，而非完全替換。秩越高，調整能力越強，但參數量也越多。通過這種方式，LoRA 能用極少的參數量（原始模型的約 0.1%-1%）來適應新任務，同時保留模型的基本能力。

這就好比是在一幅畫上添加少量的筆觸來改變其風格，而不是重新繪製整幅畫。
